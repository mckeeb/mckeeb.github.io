# mckeeb.com — v2

Static one-page personal site for Brian McKee / KD9ADR.

## Files

- `index.html`
- `styles.css`
- `script.js`

## Deploy

Replace the existing site files in the GitHub Pages repository with these three files and push.

No build step is required.

## Data

The page uses the public POTA activator stats endpoint for KD9ADR at runtime. If that endpoint is unavailable, the page gracefully shows dashes and remains fully usable.

QRZ award information is presented from the public KD9ADR profile.

## Privacy

There are **no email addresses or email links anywhere in the site**. There is no `mailto:` link.

## Domain / email

If mckeeb.com already uses GitHub Pages, no site-side DNS change is needed. Keep any existing MX records intact if the domain is also used for email.
